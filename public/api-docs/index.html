JSON Studio API

Validate, format, minify, sort and fix JSON from your own code with one POST request.

By Veerabhadra R · Updated 12 November 2026

Key takeaways

  • The API has five actions: validate, format, minify, sort and fix.
  • Send JSON as text in a json field, or as a plain text body.
  • Valid JSON returns status 200, and invalid JSON returns 422 with the line, column and a fix.
  • Requests can be up to 2 MB.

JSON Studio has a free JSON API. It uses the same checker as the website, so you get the same line, column and fix for every error.

Endpoints

MethodPathWhat it does
GET/api/healthChecks the server is running
POST/api/validateChecks JSON and returns stats or the error
POST/api/formatPretty prints JSON
POST/api/minifyRemoves all extra spaces
POST/api/sortSorts keys from A to Z
POST/api/fixRepairs common mistakes

Request

Send your JSON as text inside a json field. indent is optional: 2, 4 or "tab".

curl -X POST https://veerabhadra-json.vercel.app/api/validate \
  -H "Content-Type: application/json" \
  -d '{"json": "{\"name\": \"Ravi\",}"}'

You can also send the raw JSON as plain text:

curl -X POST "https://veerabhadra-json.vercel.app/api/format?indent=4" \
  -H "Content-Type: text/plain" \
  --data '{"name":"Ravi"}'

Response

The status is 200 when the JSON is valid and 422 when it has an error.

{
  "action": "validate",
  "valid": false,
  "error": {
    "message": "Extra comma before }",
    "hint": "Remove this comma. The last item in an object has no comma after it.",
    "pos": 15,
    "line": 1,
    "col": 16
  },
  "output": null,
  "processedBy": "server"
}

From JavaScript

const res = await fetch("https://veerabhadra-json.vercel.app/api/validate", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ json: myText })
});
const result = await res.json();
if (!result.valid) console.log(result.error.line, result.error.hint);

Limits

  • Maximum size: 2 MB per request.
  • Calls from other websites are allowed (CORS is open).

Frequently asked questions

Is the JSON Studio API free?

Yes. You can call it without a key. Please keep requests reasonable.

Why does invalid JSON return status 422?

The request itself worked, but the JSON you sent has an error. 422 means the content couldn’t be processed, and the response includes the line, column and fix.

Can I call the API from another website?

Yes. Cross-origin requests (CORS) are allowed.
