Questions

      
What is JSON Studio?
JSON Studio is a free JSON formatter and validator. It checks JSON as you type and shows the exact line, column and a plain-English fix for every error.

      
Why is my JSON invalid?
The most common causes are a trailing comma, single quotes instead of double quotes, keys without quotes, comments, and missing commas between items.

      
How do I fix a trailing comma in JSON?
Remove the comma after the last item in the object or list. JSON Studio points to the exact comma, and the Fix button can remove it for you.

      
What is the difference between format and minify?
Format adds line breaks and indentation so JSON is easy to read. Minify removes all extra spaces so the file is as small as possible.

      
Can I use JSON Studio from my own code?
Yes. Send a POST request to /api/validate, /api/format, /api/minify, /api/sort or /api/fix with your JSON as text.

      
What happens if the server is offline?
The page switches to checking in your browser with the same code, so it keeps working. The badge at the top shows which mode you’re in.
