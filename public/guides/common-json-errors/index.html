10 common JSON errors and how to fix them

Your JSON won’t parse and the error message isn’t helping. One of these ten mistakes is almost always the reason.

By Veerabhadra R · Updated 12 November 2026

Key takeaways

  • The most common JSON error is a trailing comma after the last item.
  • JSON needs double quotes around every key and every piece of text.
  • Comments, single quotes, True/None and NaN are not allowed in JSON.
  • Fix the first error first, because one mistake can cause others.

Most invalid JSON comes from the same few mistakes. Here are the ten most common, each with a broken example, the corrected version, and the fix. You can paste any of them into JSON Studio to see the exact line and column.

Check your JSON now

The 10 errors

  1. Trailing comma
  2. Single quotes
  3. Keys without quotes
  4. Missing comma
  5. Missing colon
  6. Comments
  7. Python or JavaScript values
  8. Unclosed bracket or brace
  9. Line break inside a string
  10. Numbers with a leading zero

1. Trailing comma

An extra comma after the last item in an object or list.

✗ Invalid{
  "name": "Ravi",
  "age": 30,
}
✓ Valid{
  "name": "Ravi",
  "age": 30
}

Fix: Remove the comma after the last item.

2. Single quotes

JSON only accepts double quotes for keys and text.

✗ Invalid{'name': 'Ravi'}
✓ Valid{"name": "Ravi"}

Fix: Replace every ' with ".

3. Keys without quotes

JavaScript allows this, but JSON doesn’t.

✗ Invalid{name: "Ravi"}
✓ Valid{"name": "Ravi"}

Fix: Put every key in double quotes.

4. Missing comma

Two items next to each other with nothing between them.

✗ Invalid{
  "name": "Ravi"
  "city": "Bangalore"
}
✓ Valid{
  "name": "Ravi",
  "city": "Bangalore"
}

Fix: Add a comma between the items.

5. Missing colon

A key must be followed by a colon before its value.

✗ Invalid{"score" 85}
✓ Valid{"score": 85}

Fix: Add : between the key and the value.

6. Comments

JSON has no comment syntax at all.

✗ Invalid{
  "level": "easy" // change later
}
✓ Valid{
  "level": "easy"
}

Fix: Delete the comment, or store notes in a normal field such as "note".

7. Python or JavaScript values

True, False, None, undefined and NaN aren’t JSON.

✗ Invalid{"active": True, "reviewer": None}
✓ Valid{"active": true, "reviewer": null}

Fix: Use lowercase true, false and null.

8. Unclosed bracket or brace

Every { needs a } and every [ needs a ].

✗ Invalid{
  "options": ["A", "B", "C"
}
✓ Valid{
  "options": ["A", "B", "C"]
}

Fix: Add the missing ] or }. Formatting the JSON makes this easier to spot.

9. Line break inside a string

Text can’t continue onto the next line.

✗ Invalid{"text": "First line
Second line"}
✓ Valid{"text": "First line\nSecond line"}

Fix: Write \n instead of pressing Enter inside the string.

10. Numbers with a leading zero

JSON numbers can’t start with 0, except 0 itself or 0.5.

✗ Invalid{"code": 007}
✓ Valid{"code": "007"}

Fix: Remove the zero, or put the value in quotes if the zero matters.

How to find the error quickly

  1. Paste your JSON into JSON Studio. It points to the exact line and column.
  2. Fix the first error only. One mistake can cause others further down.
  3. Check again, and repeat until it says “Valid JSON”.
  4. For lots of small mistakes, use Fix to repair trailing commas, quotes and comments in one click.

Frequently asked questions

What is the most common JSON error?

A trailing comma: an extra comma after the last item in an object or list. JSON doesn’t allow it, even though JavaScript does.

Why does JSON not allow single quotes?

The JSON standard only defines double quotes for strings and keys. Single quotes make the JSON invalid.

Can JSON have comments?

No. JSON has no comment syntax. Remove comments, or keep notes in a normal field such as "note".

How do I find where my JSON is broken?

Paste it into a validator such as JSON Studio. It shows the exact line and column of the first error and how to fix it.
